## 💡 Sobre o Projeto

Este portfólio foi desenvolvido com foco em:

- ✨ Design moderno e minimalista  
- 📱 Responsividade total  
- ⚡ Animações fluidas  
- 🧱 Arquitetura escalável para futuras updates  
- 🎥 Vídeo de fundo otimizado para mobile + desktop  

---

## 🛠️ Tecnologias Utilizadas

- ⚡ **Next.js**  
- 🎨 **Tailwind CSS**  
- 🎞️ **Framer Motion** — animações suaves e performáticas  
- 🎯 **clsx** — classes condicionais  
- 🔔 **React Toastify** — alerts modernos  
- 🔧 **React Hooks** (useState, useEffect, useRef...)  
- 🎨 **Lucide React** — ícones SVG  
- 📩 **Resend** — envio de e-mail do formulário de contato  

---

## ✨ Features

- 🧩 Seções animadas com Framer Motion  
- 📨 Formulário de contato funcional com Resend  
- 📱 Layout totalmente responsivo  
- 🎬 Vídeo de background otimizado (MP4)  
- 🎚️ Organização com clsx  
- 🔥 Ícones modernos com Lucide
